# Agent Browser Pack

Adds the `agent-browser` skill for browser-driven UI verification, screenshots,
accessibility snapshots, and console/network/error triage.

## Prerequisites

Install `agent-browser` and keep it on `PATH`.

## Usage

```toml
[imports.agent-browser]
source = "../packs/flywheel/agent-browser"
```

The Flywheel `all` pack already imports this pack.
